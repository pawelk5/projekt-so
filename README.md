# projekt-so
## Budowanie
### Wymagania
- CMake >= 3.24
- GCC >= 13.3.0 (wspierający standard C++ 20)

Aby zbudować należy skorzystać z dołączonego skryptu.
```bash
./build.sh
```
Pliki wykonywalne zostaną przekopiowane do katalogu bin.

Projekt był testowany na Linux Mint 22.2 (Ubuntu 24.04 LTS).
